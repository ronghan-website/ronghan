## Ajouter un document depuis GitHub

1. Ouvrir ce dossier dans le dépôt GitHub.
2. Choisir **Add file → Upload files**, déposer le PDF, puis enregistrer avec **Commit changes**. Préférer des noms sans espaces, par exemple `td-01.pdf`.
3. Ouvrir `teaching/p1-ul3ma260-2026.html` et cliquer sur le crayon pour modifier la page.
4. Dans la rubrique correspondante, remplacer le message « Aucun… disponible pour le moment » par une liste de liens. Par exemple, pour une feuille de TD :

```html
<ul class="materials-list">
    <li><a href="materials/p1-ul3ma260-2026/td-01.pdf">Feuille de TD 1 (PDF)</a></li>
</ul>
```

5. Pour les documents suivants, ajouter simplement une ligne `<li>…</li>` dans cette liste.
6. Enregistrer les modifications. Si GitHub Pages publie la branche modifiée, attendre la fin de son déploiement puis vérifier le lien sur la page du cours.

Le dépôt d’un PDF ne crée pas automatiquement son lien sur la page : il faut aussi effectuer l’étape 4 ou 5. Ce site statique ne comporte pas de formulaire d’envoi de fichiers. Les documents publiés dans ce dépôt public sont accessibles à tous ; ne déposer que les supports destinés à être partagés.
